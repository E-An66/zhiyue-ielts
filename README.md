# 知阅 · AI 英语阅读

根据参考视频持续精进的雅思学习网站。本地可直接打开 `index.html`；部署到 HTTPS 网站后可在平板安装到主屏幕并离线打开基础页面。

## 已实现

- 清晰的雅思听、说、读、写今日训练首页
- 剑雅 14–21、每册 Test 1–4、Listening / Reading / Writing / Speaking 完整选择目录
- 正版题目 PDF、图片、音视频和文本的本机导入与 IndexedDB 保存
- 文章资料库、分类筛选、搜索与阅读进度
- 文本、图片、PDF、网页四种导入入口
- 鼠标自由选择普通单词、短语或整句，右侧自动显示对应解释
- 阅读辅助：词义、长难句结构、全文摘要和个人笔记
- 一键加入词汇库、相关词批量收藏、浏览器发音
- 听力 Section 1–4 自由切换，每节 3 篇、共 12 篇可选素材，覆盖日常对话、生活独白、教育讨论与学术讲座
- 听力播放、暂停、继续、重播、变速、答题反馈与听力原文
- 独立精听模式：盲听主旨、逐句听写、原文核对、错因标记、跟读复述
- 独立“精听听写”模块：听写准确率、错句队列、脱稿复述与 D1/D3/D7 间隔复习
- AI 跟读研判：麦克风录音、浏览器语音识别、原声回放、逐词对齐、漏词/替换/多词诊断及准确度、完整度、清晰度、语速报告
- 口语 Part 1–3 自由切换，支持题目朗读/暂停、计时/暂停及浏览器语音转文字
- 写作 Task 1 / Task 2 草稿、字数统计和提交检查
- 词汇搜索、删除、CSV 导出与艾宾浩斯式复习卡片
- 阅读量、词汇量、连续学习、能力等级和主题分布分析
- 桌面端、平板和手机端响应式布局
- PWA 安装与离线缓存，可添加到 iPad/Android 平板主屏幕
- 学习备份导出/恢复，用 JSON 文件在电脑和平板之间迁移词汇、文章、笔记和练习记录
- 专注模式及常驻“退出专注模式”按钮

所有文章、词汇和笔记数据都保存在浏览器 `localStorage` 中，不会自动上传。
用户导入的剑雅题目和媒体文件保存在当前浏览器的 `IndexedDB` 中，不会上传。剑桥雅思试题、答案及音频受版权保护，项目只提供正版资料的本地管理和训练工具，不内置或分发盗版真题。
语音研判依赖最新版 Chrome 的麦克风与 Web Speech 支持；结果用于训练反馈，不等同于官方 IELTS 口语评分。

## 运行

双击 `index.html`，或在本目录启动任意静态文件服务器。

## 平板使用

1. 将本目录发布到 GitHub Pages 等 HTTPS 静态网站。
2. iPad 使用 Safari 打开网址，点“分享 → 添加到主屏幕”；Android 平板点击网站中的“安装到设备”。
3. 电脑侧点“设备迁移 → 导出学习备份”，把 JSON 文件发送到平板，再在平板同一位置恢复。

学习记录默认按浏览器分别保存，不会自动上传或实时同步。剑雅 PDF、图片、音视频保存在 IndexedDB 中，备份文件不包含这些大型媒体，需要在平板上单独导入。

目录已包含 `.github/workflows/deploy-pages.yml`，推送到 GitHub 公共仓库的 `main` 分支后可由 GitHub Pages 自动发布。
